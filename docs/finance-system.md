# 個人財務系統規格

這份文件是 `index.html` 那套模型的純文字版本，方便直接搬到試算表、Notion
或任何記帳 App 去實作。網頁版只是這份規格的一個實作。

---

## 1. 核心公式

```
ΔW = (I − E) + W × r_net − T − W × i
```

| 符號 | 意義 | 可控程度 |
|---|---|---|
| `I` | 收入 | 中（成長慢，但上限高） |
| `E` | 支出 | **高（立即、確定、無風險）** |
| `r_net` | 稅後報酬率 | 低（市場決定，只能選配置） |
| `T` | 稅負 | 中（合法節稅是確定報酬） |
| `i` | 通膨 | 不可控（但決定了「不投資」也是一種虧損） |

優先順序直接由「確定性」決定：先做 `E` 和 `T`，最後才處理 `r`。

## 2. 三層帳本

| 層 | 內容 | 回答的問題 | 頻率 |
|---|---|---|---|
| L1 交易層 | 每一筆錢的移動 | 錢去哪了 | 每天，30 秒 |
| L2 分類層 | 壓縮成 5 個桶 | 結構健不健康 | 每月結算 |
| L3 資產層 | 資產負債快照 | 我真的變有錢了嗎 | 每月 1 號 |

### L1 欄位規格（也是 CSV 欄位）

```
date,type,account,amount,category,nature,purpose,note
```

| 欄位 | 值域 | 說明 |
|---|---|---|
| `date` | `YYYY-MM-DD` | |
| `type` | `income` / `expense` / `transfer` | **投資投入記為 transfer，不是 expense** |
| `account` | 現金 / 數位帳戶 / 薪轉戶 / 信用卡 / 證券戶 / 退休金 | L3 的彙總鍵 |
| `amount` | 正數 | 正負號由 `type` 決定 |
| `category` | 10～15 個，不要更多 | 超過 15 個，分類本身就變成負擔 |
| `nature` | `fixed` / `variable` | 固定支出＝未來 12 個月的負債 |
| `purpose` | `need` / `want` / `invest` | 唯一真正驅動決策的欄位 |
| `note` | 自由文字 | 只寫「為什麼花」 |

建議分類：飲食、居住、交通、通訊、保險、醫療、日用、教育成長、娛樂、旅遊、
人情、稅費、投資、薪資、獎金、副業、其他。

### 四象限處理原則

|  | need 必要 | want 想要 |
|---|---|---|
| **fixed 固定** | **優化區** — 砍不掉，但可重新議價。一年檢查一次，一次省一整年。 | **止血區** — 訂閱制、月費。最危險的一格，每季稽核一次。 |
| **variable 變動** | **維持區** — 設總額上限，不設細項。別在這裡耗意志力。 | **快樂區** — 不該砍到零。給固定預算，花完為止。 |

### L2 五桶配置（比例是起點，不是教條）

| 桶 | 參考比例 | 帳戶 | 規則 |
|---|---|---|---|
| 生活必要 | 50% | 薪轉戶 | fixed + variable 的 need |
| 投資 | 20% | 證券戶／退休金 | **發薪日隔天自動轉帳** |
| 緊急預備金 | 10% | 獨立高利活存 | 滿 6 個月支出後併入投資桶 |
| 自我成長 | 10% | 薪轉戶 | 報酬率最高、也最常被砍的一桶 |
| 快樂 | 10% | 獨立簽帳卡 | 刷爆就停，不從別桶挪錢 |

唯一不可妥協的原則：**先付錢給自己**。投資在月初轉走，不是月底看剩多少。

### L3 快照

```
淨資產 = (現金 + 投資市值 + 退休金 + 不動產) − (信用卡 + 信貸 + 房貸 + 學貸)
```

一張試算表、一列一個月，永遠不要開第二張表。一年後得到 12 列 —— 那是財務病歷。

**快照有一個系統性偏誤，要知道它的存在**：如果固定在月初拍，那時上期卡費剛繳清、
新帳單還沒結出來，從結帳日到拍照日之間的消費是隱形的。以日均 × 天數估算，
通常會讓淨資產高估三五萬。

好消息是這個偏誤每個月都一樣，所以 **月增額仍然可信，只有絕對值偏高**。
兩個處理方式：心裡固定扣掉那個數，或在負債列記一筆「卡費（已消費未結帳，估）」。
真正重要的是**每次都在週期的同一個位置拍**，否則比較的是谷底和山頂。

## 3. 六個指標

| 指標 | 算法 | 參考值 |
|---|---|---|
| 儲蓄率 | `(I − E) / I` | ≥ 20%，40% 更好 |
| 固定支出比 | `固定支出 / I` | < 50% |
| 緊急金月數 | `(流動現金 − 本月應繳卡費) / 實際每月需求` | 上班族 6，自由工作者 12 |
| 負債比 | `總負債 / 總資產` | < 50%，月還款 < 收入 35% |
| **可支配財富 DW** | `淨資產 − 緊急預備金目標 − 12 個月已承諾 − 已指定用途資產 − 退休金帳戶` | 逐月成長 |
| 財務自由度 | `被動收入 / 月支出` | 1.0 = 自由 |

計算時的一致性規則：

- `transfer` 不計入收入或支出（它只是錢換位置）。
- `purpose = invest` 的支出視為投資投入，不計入 `E`，否則儲蓄率永遠難看。
- 信用卡「刷卡」當下就記為支出，還款記為 `transfer`，避免重複計算。
- **緊急金月數要先扣掉本月應繳卡費**。那筆錢這個月就會離開帳戶，不是你的緩衝。
- **DW 要扣掉「名目上在帳上，但不能調度」的錢**，有兩類：
  - **已指定用途資產**：子女教育金、購屋頭期款。它有主人了，只是還沒付出去。
  - **退休金帳戶**：勞退專戶這類鎖到法定請領年齡的錢。它是你的資產、要計入淨資產，
    但不能拿來投資或應急，所以不是「可支配」。
- DW 是負數不代表失敗，它只是誠實地說「你的錢都有去處了」。

## 4. 用帳單回推真實的必要支出

「月必要支出」是整套系統裡最容易填錯、也最影響結果的數字。預備金目標、緊急金月數、
可支配財富全部建立在它上面。憑印象填，誤差可以到四倍以上。

正確做法是用**過去 12 個月的實際帳單**回推，但有四個坑。

### 坑 1：要記「本期消費」，不是「本期應繳總額」

信用卡帳單上這兩個數字不一樣。有未繳餘額時：

```
本期應繳總額 = 上期未繳 + 本期消費 + 循環利息
```

直接抓應繳總額，上期欠的那筆會被算兩次。要抓帳單摘要列的
**「本期帳款」**或明細最後的**「正卡本期消費」**（後者含循環利息，再減掉即可）。

### 坑 2：一次性、年度性、常態要分三類

| 類別 | 例子 | 怎麼處理 |
|---|---|---|
| 一次性 | 家具、家電、搬家 | 從基準剔除，不會再發生 |
| 年度性 | 保費、牌照稅、旅遊、報稅 | **留在基準裡**，一年份的帳單自然包含它 |
| 常態 | 飲食、油錢、停車、訂閱 | 基準的主體 |

最常見的錯誤是把年度性誤當一次性剔除。判準只有一句：
**明年同一個月還會再來嗎？** 車險會、冰箱不會。

「一次性」的分類會隨事實改變。一台準備賣掉的車，它的維修是一次性；
決定留著備用，同一筆就變成常態；後來過戶給家人，又變回一次性。
分類跟著事實走，不是跟著直覺走。

### 坑 3：資料不滿一年時，用中位數而不是平均

單月的大額支出會把平均整個拉歪：

```
三個月卡費 48,000 / 52,000 / 140,000（含年繳保費與機票）
  平均    80,000  ← 推出來的必要支出高到離譜
  中位數  52,000  ← 接近真實水位
```

**不滿 12 個月用中位數，滿 12 個月改用平均。** 滿一年之後平均才是對的，
因為整年的帳單已經自然涵蓋了所有年度性支出，用中位數反而會低估。

### 坑 4：不要雙重計算年度不規則支出

如果已經用滿 12 個月的實際帳單平均，那些保費、機票、修車**已經在裡面了**。
這時再填一個「年度不規則支出」欄位去攤提，等於算兩次。

```
資料滿 12 個月：  月必要支出 = 常態卡費平均 + 非卡費必要支出
                  （年度不規則支出欄位設為 0）

資料不滿一年：    月必要支出 = 常態卡費中位數 + 非卡費必要支出
                               + 年度不規則支出 ÷ 12
```

### 別忘了不走信用卡的支出

房租、水電、牌照稅、燃料費、現金生活費、轉帳扣款 —— 這些不會出現在卡費裡。
牌照稅（4 月）和燃料費（7 月）特別容易漏，因為多數人用超商或轉帳繳。
把它們加總成一個「非卡費必要支出」月數字，和卡費分開記。

### 檢查：三邊要對得起來

```
年收入 − 年支出 ≈ 這一年淨資產的增加
```

對不上就是有東西沒抓到：漏記的收入來源、用現金付的大額支出、
或是某個帳戶根本沒列進資產表。這個交叉檢核每年做一次，比任何單一數字都有用。

## 5. 理財工具分層

| 層 | 工具 | 這筆錢的期限 |
|---|---|---|
| L0 現金流增益 | 信用卡回饋、固定支出議價、訂閱稽核、報稅扣除額 | 立即 |
| L1 流動性 | 數位高利活存、分拆定存、貨幣市場基金、短債 | 0–12 個月 |
| L2 防禦 | 實支實付、重大傷病、定期壽險、失能扶助、第三人責任 | 保障期間 |
| L3 稅務優惠 | 勞退自提、儲蓄投資特別扣除額、列舉扣除、境內外所得配置 | 至法定請領 |
| L4 核心投資 | 全球／台股市值型 ETF、公債與投等債 ETF、定期定額 | 10 年以上 |
| L5 衛星槓桿 | 個股、主題 ETF、自住房貸、外匯與加密資產 | 可歸零的錢 |

兩條硬規則：

1. **儲蓄型保單不列入投資工具。** 保障與投資綁一起，兩邊效率都差，
   前幾年解約必虧。要保障買定期險，要投資買 ETF。
2. **核心部位的目標不是打敗市場，是讓你能安穩持有十年。**
   會讓你半夜賣出的配置，再漂亮也是錯的。

## 6. 資金配置瀑布（每一塊閒錢的去向）

原則：把錢放到「稅後、風險調整後報酬率」最高的地方。
還掉 12% 的卡債 = 賺到無風險的 12%，沒有投資能穩定贏它。

1. 備齊 1 個月生活費的週轉金
2. 拿滿公司提撥／補助這類「免費的錢」
3. 清光年利率 > 8% 的負債（雪崩法：先殺利率最高的）
4. 緊急預備金補到 6 個月
5. 買齊 L2 防禦型保險
6. 用滿稅務優惠額度
7. 核心投資定期定額
8. 清 3–8% 中利負債，剩餘才進衛星部位

例外：有催收中或即將違約的債務，先處理它 —— 信用瑕疵會讓未來每一筆貸款都變貴。

## 7. 退休規劃：台灣的三層，與 Coast FI

### 不要直接套用美國的 FI 數字

英文圈的 FI（Financial Independence）計算幾乎都假設退休金**完全自備**，
因為美國的社會安全給付相對薄。台灣不一樣，有兩層是強制的：

| 層 | 內容 | 性質 |
|---|---|---|
| 第一層 | 勞保老年年金 | 依投保年資與投保薪資計算，活到老領到老 |
| 第二層 | 勞退新制個人專戶 | 雇主強制提繳 6%，另可自提 6% |
| 第三層 | 自己的投資 | FI 計算通常只看這層 |

把前兩層折算成等值資產（年金 ÷ 提領率），自備的缺口通常會少掉一大半。
**直接套用美國的表，會讓你以為差得比實際遠得多。**

兩層的實際金額請用官方工具查，不要用估的：

- 勞退專戶餘額、累計提繳年資 → 勞保局 e 化服務系統
- 勞保老年年金預估 → 勞保局的年金試算服務

### 雇主的 6% 是資金瀑布的第 2 步

勞退的雇主提繳不從你薪水扣，是法定義務外加給你的。以月提繳工資上限計，
一年十萬出頭 —— 這是「免費的錢」，報酬率無限大。

所以**換工作的空窗期、或沒有投保單位的期間，是有成本的**，而且無法補回。

自提 6% 則是另一回事：它是你自己的錢，但**全數從當年度綜合所得總額扣除**，
等於立刻拿到等同邊際稅率的報酬。額度逐年計算，**用不完就過期**。
自營作業者、實際從事勞動之雇主也可以自願提繳，節稅效果一樣。

### 換工作時：勞保與勞退的規則不同

- **勞退可以真的回溯**：雇主應自到職日起按月提繳，漏掉的可要求補提繳。
- **勞保的保險效力不能回溯**：依勞工保險條例，投保單位未於到職當日申報者，
  保險效力自**通知之翌日**起算。公司把到職日填早一點，年資認列通常沒問題，
  但那段期間**實際上沒有職災、傷病、失能保障**。

所以交接期要做兩件事：催新公司盡快申報，以及確認商業保險（意外、實支實付醫療）
在這段期間有效 —— 商業保險不受就業狀態影響，正好補這個空窗。

### Coast FI：比完全自由更早的里程碑

```
Full FI  = 年支出 × 25            （4% 提領率）
Coast FI = Full FI ÷ (1 + r)^剩餘年數
```

Coast FI 的意思是：**現在投入的錢已經夠多，光靠複利就能在退休年齡長到 Full FI，
之後一塊錢都不用再存。** 達到之後你還是要工作，但只需要賺到當下的生活費。
它給的是選擇權 —— 可以換低薪但喜歡的工作、減少工時、創業。

**最大的陷阱是報酬率用名目還是實質。** 網路上多數 Coast FI 計算機用 7% 年報酬，
但「期望的退休年支出」填的是今天的購買力。兩者混用等於假裝通膨不存在：

```
年支出 100 萬、25 年後退休
  用 7% 名目       Coast FI = 2,500 萬 ÷ 5.43 =  460 萬
  用 4.4% 實質     Coast FI = 2,500 萬 ÷ 2.94 =  851 萬   ← 差了快一倍
```

**實質報酬 ≈ 名目報酬 − 通膨。** 看到任何 FI 計算機，第一件事就是確認它用哪一個。
如果支出填的是今天的錢，報酬率就必須是實質的。

### 目標導向的錢，配置由「期限」決定

子女教育金、購屋頭期款這類有明確用途與時程的錢，不該和退休金混在一起看：

| 距離動用 | 配置 |
|---|---|
| 3 年內 | 定存、短天期公債，完全不碰股票。有截止日的負債虧不起 |
| 3–7 年 | 股債混合，到期前兩年開始分批轉現金 |
| 10 年以上 | **放現金才是真正的風險**。可配置股票，動用前 3 年開始分批轉出 |

還有一個常被誤判的點：**如果這筆錢將來要用外幣付掉（留學、海外置產），
持有該外幣就不是匯率風險，而是正確的貨幣配對。** 用本國貨幣資產去付未來的外幣負債，
才是在賭匯率。

## 8. 執行節奏

| 週期 | 時間 | 動作 |
|---|---|---|
| 每天 | 30 秒 | 記 L1 |
| 每週 | 5 分鐘 | 對帳戶餘額、看「想要」花了多少 |
| 每月 | 20 分鐘 | 結算六指標、拍 L3 快照、確認自動轉帳有執行 |
| 每季 | 1 小時 | 訂閱稽核、檢查配置偏離 |
| 每年 | 半天 | 固定支出議價、保單檢視、報稅試算、再平衡 |

系統能不能活下來，取決於每次動作夠不夠短。

## 免責

一般性資訊與教育內容，不構成投資建議、稅務建議或任何金融商品推介。
稅制級距、扣除額、門檻與利率年年變動，上文寫的是「該去查哪些項目」，
實際數字以當年度官方公告為準；金額大時請諮詢合格會計師或理財顧問。
投資有風險，過去績效不代表未來表現。
